# Мониторинг и управление вентиляторами ноутбука (Windows 11)

Этот проект представляет собой программу на Python с веб-интерфейсом для мониторинга состояния ноутбука и попытки управления вентиляторами.

## Возможности
- 📊 **Мониторинг загрузки CPU** в реальном времени.
- 💾 **Использование оперативной памяти**.
- 🌡️ **Температура процессора** (эмуляция/расчет на основе нагрузки, так как прямой доступ требует драйверов).
- ⚡ **Расчетное энергопотребление**.
- 🌀 **Обороты вентилятора** (RPM).
- 🎛️ **Ползунок управления скоростью вентилятора**.

## Как установить и запустить

### Требования
- Windows 10/11
- Установленный **Python 3.x** (скачать с python.org).
  - ⚠️ **Важно:** При установке Python поставьте галочку **"Add Python to PATH"**.

### Установка (Автоматическая)
1. Скачайте все файлы проекта в одну папку.
2. Запустите файл **`install_and_run.bat`**.
3. Скрипт сам проверит Python, установит нужные библиотеки (`psutil`) и предложит запустить программу.

### Ручной запуск
Если установка уже пройдена:
1. Откройте командную строку в папке с программой.
2. Введите: `python app.py`
3. Или просто запустите **`start_monitor.bat`**.

### Использование
После запуска программа автоматически откроет браузер по адресу `http://localhost:8080`.
- Вы увидите дашборд с показателями.
- Используйте ползунок внизу для изменения целевой скорости вентилятора.

## ⚠️ Важное примечание про управление вентиляторами
Прямое управление вентиляторами на ноутбуках — сложная задача из-за ограничений BIOS и контроллеров Embedded Controller (EC).
- **Эта программа** отправляет команду на изменение скорости.
- Если ваш ноутбук не поддерживает программное управление через стандартные API (что бывает часто), вентилятор может не изменить обороты немедленно.
- Для реального управления на специфичных моделях (MSI, Lenovo, Dell) часто требуются утилиты вроде *NoteBookFanControl* или *FanControl*, которые работают на уровне драйверов.
- Данный код предоставляет **интерфейс и логику**, которую можно расширить, добавив вызов конкретных утилит для вашей модели ноутбука в файле `app.py` (функция `set_fan_speed`).

## Структура файлов
- `app.py` — основной код программы (сервер + логика).
- `install_and_run.bat` — скрипт установки и первого запуска.
- `start_monitor.bat` — скрипт быстрого запуска после установки.
- `README.md` — этот файл с инструкцией.
